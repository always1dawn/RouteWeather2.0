# RouteWeather 2.0 · 山途智行（本地开发副本）

线上地址：<https://xzl2007.github.io/route-weather/>

本目录是线上版本的完整静态副本，并在其基础上做了 2026-11 的体验与数据升级。
无构建步骤，改完刷新即可。

```powershell
python -m http.server 8124 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8124/>。

## 本次改动

### 1. 地名搜索：多结果 + 明确坐标
- `js/geocode.js` 从天地图 `geocoder`（只返回一个点）改为 `v2/search`，一次返回多个 POI。
- 按行政区级别、景区类型、精确名称重排；「黑水」现在第一条是**四川省阿坝州黑水县**（32.06388°N, 102.98824°E），陕西/云南的同名地点排在后面。
- 每条结果显示「行政区 / 景区 / 乡镇」类型、完整地址、5 位经纬度，点击即添加；新增内置点位「黑水」及达古冰川、奶子沟、色尔古等川北点位。
- 搜索弹层加高，结果区域可滚动，不再只露出一条。

### 2. 字号与可读性
- 新增 `css/readability.css`（最后加载），统一放大正文、按钮、卡片、报告、搜索结果的字号与行高。
- 允许路线名、POI 名、地址换行，取消过度省略；移动端单独调整，避免压缩成 8–10px。
- 首页手机端给 hero 文案加了浅色衬底，雪山背景上也能看清。

### 3. 住宿 / 美食 / 景点推荐质量
- `js/poi.js` 的推荐层增加品牌与口碑关键词加权（连锁、温泉、观景、藏式、老字号、景区门口等），剔除停车场、管委会、旅行社、设计公司等无关结果。
- 增加 `CURATED` 人工精选（羊茸哈德、达古冰川大酒店、四姑娘山阳光酒店、日松贡布、康定情歌大酒店、甲居藏寨等），标注「OTA 口碑精选」。
- 每张推荐卡提供 **大众点评 / 去哪儿 / 高德地图** 直达链接，方便复核。
- 推荐排序同时考虑出行方式、预计经过时刻、绕行距离和 30 km 分段分散，避免一屏全是同一个镇。

### 4. 自驾多路线 + 加油/充电站
- `js/routing.js` 自驾改用 Valhalla（OSM）多方案：时间优先、备选路线、少高速·风景优先；失败自动回退 OSRM。
- 报告顶部「路线方案」分栏显示每条路线的里程、用时和天气评分；默认选中天气评分最高的方案，切换后整份报告（采样点、天气、推荐、补能）一起切换。
- 加油与充电拆成两个独立分类，地图上用不同图例；智能报告新增「沿途补能」时间轴。
- 可选接入高德地图 Web 服务：在报告「沿途补能」底部填入高德 Web 服务 Key，即优先使用高德 POI（GCJ-02 自动转 WGS-84）。Key 只保存在本机 `localStorage`。

### 5. 穿衣 / 户外防护 / 高海拔含氧量
- `js/scoring.js` 新增 `oxygenAt()`、`clothingAdvice()`、`protectionAdvice()`、`buildGearPlan()`。
- 智能报告最后新增「穿衣 · 防护 · 含氧量」：
  - 按体感温度、风速、降水、海拔分层给出穿衣建议；
  - 防晒、防雨、防风、雷暴、结冰、高原防护；
  - 最高点等效含氧量（海平面 = 100%），并给出 2000/3000/4000/4500/5000 m 对照。
- 沿途卡片与地图弹窗在高海拔点标注「含氧 xx%」。
- 含氧量为空气氧分压相对海平面的比例，不是血氧饱和度。

## 数据源

| 用途 | 服务 |
| --- | --- |
| 逐小时天气 | Open-Meteo（CC BY 4.0） |
| 海拔 | Open-Meteo Elevation |
| 自驾路线 | Valhalla（OSM），失败回退 OSRM |
| 骑行/徒步 | BRouter |
| 底图 | 天地图（主）、OSM、Esri |
| 地名 / POI | 天地图 v2/search |
| 加油/充电（可选） | 高德开放平台 Web 服务 |
| 点评/去哪儿 | 只做搜索跳转，不抓取页面 |
